# torrcast v3 — plug-and-play

Единственная действующая спека. v1 и v2 закрыты и стёрты по решению владельца 07-08-2026;
их текст и вся история фактов — в git-истории репы. Здесь — только принципы, ограничения
и то, что ЕЩЁ НЕ закрыто.

## 1. Цель

**Инструмент, не нуждающийся в настройке: развернул — и поехал.** Однокнопочная штука для
юзеров, которые хотят и могут только plug-and-play.

Следствия, возведённые в принцип:

- **Никаких трекеров с логином.** RuTracker и подобные исключены осознанно — да, там HD
  back-catalog, но логин/капча/аккаунт убивают «развернул и поехал». Каталог — только
  открытые индексеры (Knaben-класс). Это решение владельца, не техническое ограничение.
- **Никакой ручной конфигурации на счастливом пути.** Релиз, озвучка, качество, темп,
  перекодирование — всё выбирается само. Вопросов минимум (франшиза, «Продолжить?»),
  любые — с дефолтом по Enter.
- **Молчаливых подмен нет**: каждое авто-решение печатается одной честной строкой
  («релиз №1 на деле 574p — беру №2», «тяжёлые куски перекодирую на ходу»).

Критерий успеха прежний: владелец говорит `cast <фильм>`, жмёт Enter один-два раза и
досматривает до титров, ни разу не задумавшись о торрентах.

**Глобальная формула владельца (07-08): «что ни запросил — оно взяло и включилось».**
Без подгрузов; по возможности без просадки качества на всём пути; в крайнем случае
качество роняем, но подгрузы не допускаем никогда. Плавность > пиковая чёткость.

README — часть продукта: всегда актуальный и правильный (команды сверены с фактическим
CLI), с честным дисклеймером: приёмник разработки и тестирования — Samsung Q70D
(встроенный Chromecast); на других приёмниках не тестировалось.

## 2. Принципы разработки (унаследованы из v1/v2, действуют всегда)

- **Оркестратор руками не кодит, не дебажит, не ковыряет стенд** — его контекст обязан
  дожить до конца работ. Кодинг/отладка/прогоны/выкатки — субагенты.
- **Субагенту — цель и ограждения, не рецепт.** Сам выбирает путь, сам дебажит, возвращает
  результат. Требовать **доказательство, а не отчёт о работе**: цифры, логи, воспроизведение.
  Честное «не сошлось» — валидный результат.
- **Приёмка — только живой Q70D.** Mock — регрессия в тестах; «на mock работает» не
  засчитывается ни в каком виде. Физический экран агенты не видят — финальное «вижу
  картинку» всегда за владельцем.
- **Агентам — только короткие смоки на ТВ** (старт → картинка → минуты → stop). Длинные
  прогоны (20+ мин, фильм, серия целиком) — владелец при реальном просмотре. Если на ТВ
  что-то играет — не перебивать. ТВ в простое сам выключается; включалка — pychromecast.
- **Гейт качества показа: НОЛЬ подгрузов** вне прогрева старта. Ребуфер = брак, работа
  не принимается.
- **Деплой только из репы**: репа → коммит → выкатка (`/root/torrcast` → `./install.sh`);
  после выкатки обязательная сверка venv с репой (ловили молчаливую невыкатку pip-кэшем).
  Код на стенде руками не правится.
- Параллельные исполнители разводятся по живым объектам (репа / стенд / ТВ), не по файлам;
  в одной репе — git worktree.
- Установка = `git clone` + `./install.sh`, без ручных шагов — это часть продукта, а не
  удобство разработчика.

## 3. Ограничения железа и завоёванные факты (не переоткрывать)

- **Q70D роняет сегменты тяжелее ~19 МБ** (вес, не секунды) — потолок нарезки 16 МБ.
- **Реальный потолок битрейта Q70D ~10 Мбит/с** (легенды «16» и «18–22» опровергнуты
  замерами) — всё тяжелее перекодируется в 9, бесшовно (стыки выверены по звуку И по
  ленте времени прогона).
- **HEVC на Q70D неизвестен** — не проверялся ни разу (см. §5.4).
- Приёмнику нельзя отдавать 404 — после него LOAD не берётся 2–3 минуты.
- У pychromecast все соединения `sender-0`: чужой показ невидим, наблюдать только
  владеющим сендером; castbot kinocast всегда рядом вторым сендером.
- Нарезка детерминирована (сетка от карты опорных кадров, mkv Cues / mp4 stss);
  ffmpeg `-ss` уводит на опорный кадр раньше и не обязательно ближайший — точка старта
  измеряется, не вычисляется.
- Скорость libx264 на стенде (4 vCPU): ultrafast 4.36×, superfast 2.62×, veryfast 1.54×.

## 4. Приёмка проекта (гейт, за владельцем)

- [ ] Полный фильм до титров: ноль подгрузов, без единого касания консоли.
- [ ] Сериал: серия целиком → автопереход → ещё стык → `stop` → `cast` продолжает.
- [ ] Перемотки пультом (пальцем) вперёд/назад/глубоко — картинка возвращается за секунды.
- [ ] Таймлайн и общее время на экране, «старт NN с» = момент картинки.
- [ ] «Вижу картинку» — глазами владельца.

После зелёной приёмки: **merge `v2/stability` → master** (по команде владельца) и
переезд со временного стенда CT501 на прод-гостя (VMID 1xx, `onboot=1`), разворачивание —
одним `install.sh`.

## 5. Открытые работы

Из замера покрытия топ-100 (07-08-2026: фильмы ✅92% но HD только 75%, сериалы ✅75%/HD 71%,
«не найдено» = 0, индексер за 214 прогонов не подвёл ни разу):

1. **Русские названия, находимые только латиницей** (5% фильмов / 10% сериалов топа):
   искать автоматически и по транслиту/оригинальному названию — юзер не должен догадываться,
   что «Психо» надо набирать как «Psycho».
2. **SD-фолбэк — крупнейшая дыра качества** (17 фильмов топа: «Тёмный рыцарь» 414p,
   «Матрица» 594p): селектор обязан докапываться до честного 1080p-H.264 — с динамическим
   битрейтом тяжёлые релизы допустимы. SD — только если HD в каталоге нет, и об этом
   говорится вслух.
3. **Сезон-паки**: авто-выбор сериала не должен хватать раздачу-огрызок без нужной серии
   (Наруто, Локи, Сверхъестественное: «серии s1e1 в этой раздаче нет» — а рядом лежит
   полный сезон).
4. **Аниме = HEVC** (самый провальный жанр): проверить HEVC на живом Q70D одним смоком.
   Тянет — снять фильтр для HEVC-релизов (потолок веса/битрейта остаётся); не тянет —
   решить честно (перекодирование HEVC→H.264 по замеру CPU или честный отказ строкой).
5. Мелочи, зафиксированные ревью v2 (места — в git-истории SPEC-v2 §7.4): лог
   MockReceiver, mtime замка film_keys, tmp-имя кэша карт, Feed.lock в pack_start,
   квадратичный `_both_languages`; .avi-эвристика не работает для сериалов (размер =
   сезон, судит только ffprobe).
6. Решение владельца: дефолт франшизы, когда у самой ранней картины мёртвый рой
   (сейчас — самая живая; «тачки» дают дефолт [4], спорно).

## 6. Что НЕ делаем

- Трекеры с логином/аккаунтом — ни в какой форме (см. §1).
- zapret/обходы для индексеров — троттлинга нет, каталог держит Knaben.
- Телеграм-бот, веб-морда, голос.
- Переписывание парсера, поиска, кластеризации франшиз целиком — доказаны корпусом
  21 540 имён и живой выдачей; точечные починки разрешены.
- Не трогаем kinocast (владелец им пользуется), прод-ингресс, amnezia, PBS.
