# torrcast

**作品名を入力するだけで、テレビで映画を再生。**

昼間、誰かに『マトリックス』を勧められたとします。そこから観るまでには、たいていひと手間かかります。動画配信サービスの作品一覧をスクロールしたり、あらかじめ映画をダウンロードしたり、リモコンでテレビのブラウザーに作品名を入力したり。torrcast は、観たい作品がもう決まっているときのためのツールです。その晩、`cast マトリックス` と入力すれば、面倒な操作に悩まされることなく、テレビで映画が始まります。

torrcast は映画やテレビシリーズ、アニメを探し、再生できるバージョンと音声トラックを選んで、Chromecast に動画を配信します。ターミナル、Telegram、Home Assistant から再生を始められます。

[インストール](#インストール) · [視聴](#視聴) · [Home Assistant](#home-assistant) · [Telegram](#telegram) · [コマンド](#コマンド)

![torrcast のインストールと再生のデモ](https://raw.githubusercontent.com/anysda/torrcast/master/docs/demo.gif)

- **続きも、そのまま。** エピソードは順番に再生されます。シーズンが終わると、torrcast が次のシーズンを探します。今夜は途中で止めて、明日、保存された位置から続きを観ることもできます。
- **好みの音声を覚えます。** 音声トラックは torrcast の言語設定に合わせて選ばれます。別のトラックやスタジオを選べば、その作品での選択を記憶します。
- **観ている間に先読み。** torrcast はバックグラウンドで映画をキャッシュに保存します。映画全体をディスクに保存したと通知されたら、インターネット接続がなくても最後まで観られ、早送りや巻き戻しもできます。コンピューターとテレビの間のローカル接続は引き続き必要です。
- **動画形式は torrcast にお任せ。** 受信機に合わせて必要な動画変換を行い、バージョンや音声、画質が変わると、その都度知らせます。

## 必要なもの

| 構成要素 | 要件 |
| --- | --- |
| テレビ | テレビ本体、またはテレビに接続したストリーミング端末に内蔵された Chromecast 受信機。 |
| コンピューター<br>（できれば&nbsp;サーバー） | systemd を使用する Debian 12 以降または Ubuntu、もしくは macOS。Mac へのネイティブインストールは Apple Silicon で動作確認済みです。 |
| ストレージ | 先読みとシステム用の予備領域として約 33 GB の空き容量。依存ソフトウェアとストリーミング用キャッシュのために、さらに空き容量を確保してください。 |
| ネットワーク | インターネット接続と、コンピューターと受信機が共に接続する、信頼できる家庭内ネットワーク。 |

torrcast はホームサーバーや仮想マシン、LXC コンテナーで常時稼働させ、観たくなったときにすぐ使えるように設計されています。Mac でも使えますが、再生中はコンピューターがスリープしないようにしてください。仮想マシンやコンテナーを使う場合は、LAN 上で受信機と相互に通信できることを確認してください。動画は、そのコンピューターからローカルネットワークを通ってテレビに届きます。

## インストール

テレビに動画を配信するコンピューターで、次のコマンドを実行します。

```sh
curl -fsSL https://torrcast.anysda.space | sh
```

インストーラーは最新版をダウンロードし、SHA-256 チェックサムを検証して、依存ソフトウェアのインストールとバックグラウンドサービスの設定を行います。必要に応じて管理者権限を求め、受信機が1台だけ見つかった場合は自動で設定します。インストール後の言語は英語です。`cast --ru` で保存されている言語設定をロシア語に切り替えると、ターミナルのメッセージ、ボットの返信、音声の優先設定も切り替わります。`cast --en` で英語に戻せます。

さっそく映画を再生してみましょう。

```sh
cast マトリックス
```

受信機が複数見つかった場合は、`cast --tv` で1台を選び、映画を再生するコマンドをもう一度実行してください。`cast --tv <ip>` でアドレスを直接指定することもできます。

<details>
<summary>macOS へのインストール</summary>

同じ1行のコマンドで、macOS にもネイティブにインストールできます。普段使っている管理者アカウントから実行してください。インストーラーは必要に応じて Homebrew を導入し、バックグラウンドサービスには launchd を使います。

バックグラウンドサービスからローカルネットワークにアクセスするため、再生処理は root として動作します。インストーラーは、インストールを実行したユーザーに対して、`cast` コマンドに限りパスワードなしで sudo を使えるルールを追加します。映画の再生は、引き続き `cast マトリックス` で行えます。

初期セットアップのスクリプトでは、Homebrew のセットアップに進む前に `sha256sum` が必要です。`sha256sum is required but is not in PATH` と表示されて止まった場合は、以下のリポジトリからのインストール手順を使ってください。この手順では `install.sh` を直接実行します。macOS で外部からの接続の許可を求められたら、受信機が動画ストリームにアクセスできるよう許可してください。

</details>

<details>
<summary>リポジトリからのインストール</summary>

```sh
git clone https://github.com/anysda/torrcast
cd torrcast
./install.sh
```

この方法でも、インストーラーが依存ソフトウェアの導入と管理者権限の取得を行います。ARM Linux では、ディストリビューションが ffmpeg 6.1 以降を提供していない場合、動作するものを別途用意する必要があります。インストーラーが代わりに用意する Linux 向けビルドは x86_64 用です。

</details>

## 視聴

通常は作品名だけで十分です。検索でシリーズの複数の映画が見つかる場合など、自分で映画を選びたいときは `--menu` を付けてください。

```console
$ cast マトリックス --menu
  1. マトリックス (1999) · IMDb 8.7 · 2時間16分
     ウォシャウスキー姉妹が脚本・監督を手がけたSFアクション映画。
  2. マトリックス リローデッド (2003) · IMDb 7.2 · 2時間18分
     SFアクション映画。『マトリックス』シリーズ第2作。
  3. マトリックス レボリューションズ (2003) · IMDb 6.7 · 2時間9分
     SFアクション映画。『マトリックス』シリーズ第3作。
Enter - 「マトリックス (1999)」、全3件中1件目
何を観ますか？ [1]:
```

Enter を押すと、初期選択として表示されている映画が再生されます。別の映画を選ぶには番号を入力してください。検索結果や評価、利用できるバージョンは変わることがあります。torrcast は同じ映画の各バージョンを1つの項目にまとめて表示します。映画は一度選ぶだけで、再生するバージョンの選択は torrcast に任せられます。

シリーズ作品では、シーズンと話数も指定できます。

```sh
cast キム・ポッシブル s1e1
```

次のエピソードは自動で始まります。`cast stop` で再生位置を保存でき、**引数なしの `cast` で最後に観ていたシリーズ作品の続きを再生できます**。映画の続きを観るには、もう一度その作品名を指定してください。

一時停止や早送り、巻き戻しはテレビのリモコンで操作できます。再生が始まったら、ターミナルを閉じても、SSH 接続を切ってもかまいません。torrcast がキャッシュを自動管理するので、メディアライブラリを整理する必要はありません。

## Home Assistant

torrcast をダッシュボードに追加すると、映画の再生、一時停止、早送りや巻き戻し、音量調整、次のエピソードへの移動ができます。インテグレーションはローカルネットワーク経由で torrcast に接続します。

[![torrcast を HACS に追加](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=anysda&repository=torrcast&category=integration)

1. 上記のコマンドで torrcast をインストールし、ボタンから [HACS のカスタムリポジトリ](https://www.hacs.xyz/docs/faq/custom_repositories/)として追加して、インテグレーションをダウンロードします。
2. Home Assistant を再起動します。**設定 > デバイスとサービス**で、検出された torrcast デバイスを確認して追加します。表示されない場合は、コンピューターの IP アドレスとポート `8479` を指定して、torrcast インテグレーションを手動で追加してください。
3. torrcast のメディアプレーヤーをダッシュボードに追加します。メディアブラウザーを開くと、**instant** では作品名を入力してすぐに再生でき、**menu** では検索結果から作品を選べます。

Assist でも再生を操作できます。作品名を指定して映画を再生できるかどうかは、アシスタントの対応言語によります。確認した構成では、標準の Assist は英語での再生リクエストに対応していますが、ロシア語には対応していません。この音声操作の制限にかかわらず、メディアブラウザーではロシア語の作品名を入力できます。

## Telegram

ソファに座ったまま `cast マトリックス` を送り、チャット内のボタンで再生を操作できます。映画が始まるまでの進捗をボットが表示し、その後は一時停止、停止、音量調整、30秒単位の早送りや巻き戻しのボタンが使えます。ターミナルや Home Assistant から始めた再生も操作できます。

torrcast をインストールしたコンピューターで設定します。

```sh
cast -tg
```

[BotFather](https://core.telegram.org/bots/features#botfather) でボットを作成し、そのボットとのチャットを開いて **開始**を押します。設定メニューにボットのトークンと自分のチャット ID を入力し、**Test and save**（テストして保存）を選んでください。テストメッセージが送信され、ボットのサービスが有効になります。このサービスはコンピューターの再起動後も起動します。ボットは設定したチャットからのコマンドだけを受け付けます。

<details>
<summary>チャット ID の調べ方</summary>

ボットのサービスを有効にする前に、作成したボットにメッセージを送ります。`<TOKEN>` を BotFather から受け取ったトークンに置き換え、ブラウザーで `https://api.telegram.org/bot<TOKEN>/getUpdates` を開いてください。[レスポンス](https://core.telegram.org/bots/api#getupdates)の `result[].message.chat.id` にある数値を、設定メニューの **Chat ID**（チャット ID）欄にコピーします。

</details>

次のコマンドを通常のメッセージとして送ります。

```text
cast マトリックス
cast キム・ポッシブル s1e1
cast
cast stop
```

スマートフォンは Telegram 経由でコマンドを送ります。動画の配信経路はコンピューターとテレビの間だけです。

## コマンド

| コマンド | 動作 |
| --- | --- |
| `cast <作品名>` | 映画やシリーズ作品を探して再生します。 |
| `cast <作品名> s1e1` | シーズンと話数を指定して、特定のエピソードを再生します。 |
| `cast` | 最後に観ていたシリーズ作品の続きを再生します。 |
| `cast stop` | 再生を停止し、再生位置を保存します。 |
| `cast status` | 再生中の作品、再生位置、先読みの進捗を表示します。 |
| `cast <作品名> --menu` | すぐに再生せず、見つかった作品を表示して選択を求めます。 |
| `cast <作品名> --pick N` | 選択を求めず、メニューの N 番目の作品を再生します。 |
| `cast <作品名> --new` | 同じリリース、ファイル、音声トラックを使って最初から再生します。 |
| `cast <作品名> --voice` | メニューから音声トラックを選びます。`--voice N` または `--voice スタジオ名` で選択し、その選択を保存します。 |
| `cast voices <作品名>` | 再生を始める前に、利用できる音声トラックを表示します。 |
| `cast releases <作品名>` | リリースを作品ごとにまとめて一覧表示します。同じ検索に `--release N` を付けると、指定したリリースを再生します。 |
| `cast <作品名> --dry` | テレビに配信せず、選択処理をすべて実行します。 |
| `cast --tv` | ネットワーク上の受信機を探して選びます。`cast --tv <ip>` ではアドレスを直接設定できます。 |
| `cast -tg` | Telegram ボットの設定メニューを開きます。 |
| `cast --ru` / `cast --en` | 言語を切り替え、その選択を保存します。 |
| `cast doctor` | サービス、ネットワーク、受信機を確認します。 |
| `cast log --since 2d` | 診断ログを表示します。`--since` には `2d`、`12h`、`30m`、または `YYYY-MM-DD` 形式の日付を指定できます。 |
| `cast --upgrade` | 最新版に更新します。 |
| `cast --version` | バージョンを表示します。 |
| `cast -h` | すべてのコマンドとオプションを表示します。 |

## 更新とサポート

```sh
cast --upgrade
```

更新しても、設定や選択した受信機は保持されます。何かを再生している間は、更新処理を実行できません。

映画が始まらない場合は、`cast doctor` を実行してサービス、ネットワーク、受信機を確認してください。`cast log --since 2h` で最近の再生イベントを確認でき、`cast -h` でコマンドとオプションを一覧表示できます。

不具合を報告する際は、[Issue を作成](https://github.com/anysda/torrcast/issues)し、実行したコマンド、OS、受信機の機種、問題に関連する診断出力を添えてください。
