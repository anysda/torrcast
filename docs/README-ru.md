# torrcast

**Включайте кино на телевизоре по названию.**

Днём кто-то посоветовал «Матрицу». Обычно дальше начинается возня: листать ленту стримингового сервиса, скачивать фильм заранее или набирать название с пульта в неудобном браузере телевизора. torrcast для тех, кто уже знает, что хочет посмотреть. Вечером вы набираете `cast матрица`, и фильм идёт на телевизоре, без сражения с интерфейсом.

torrcast находит фильмы, сериалы и аниме, выбирает подходящую версию и озвучку, передаёт видео на Chromecast. Запустить показ можно из терминала, Telegram или Home Assistant.

![Установка torrcast и запуск фильма](https://raw.githubusercontent.com/anysda/torrcast/master/docs/demo.gif)

- **Смотрите дальше.** Серии идут одна за другой. Когда сезон заканчивается, torrcast ищет следующий. Можно остановиться на вечер, а завтра продолжить с сохранённого места.
- **Слушайте привычную озвучку.** Дорожка подбирается по языку, который вы выбрали для torrcast. Можно выбрать другую дорожку или студию, и программа запомнит её для этого фильма или сериала.
- **Запас на случай обрыва интернета.** Пока вы смотрите, torrcast сохраняет фильм в кэш. Когда он сообщит, что фильм целиком на диске, его можно досмотреть и перематывать без интернета. Локальная связь между компьютером и телевизором по-прежнему нужна.
- **Формат подберётся сам.** Если приёмнику нужно преобразовать видео, torrcast сделает это сам. О смене версии, дорожки или качества он сообщает по ходу запуска.

## Что понадобится

| Компонент | Требование |
| --- | --- |
| Телевизор | Приёмник Chromecast, встроенный в телевизор или в подключённую приставку. |
| Компьютер<br>(лучше&nbsp;сервер) | Debian 12+ или Ubuntu с systemd либо macOS. Нативная установка на Mac проверена на Apple Silicon. |
| Диск | Около 33 ГБ свободного места для загрузки вперёд и резерва системы. Зависимости и потоковый кэш требуют дополнительного места. |
| Сеть | Доступ в интернет и общая доверенная домашняя сеть для компьютера и приёмника. |

torrcast рассчитан на постоянную работу на домашнем сервере, в виртуальной машине или LXC: захотелось посмотреть кино, и всё уже готово к запуску. Можно поставить и на Mac; во время просмотра компьютер не должен засыпать. Для виртуальной машины или контейнера проверьте, что они и приёмник видят друг друга в локальной сети. По ней же видео идёт с компьютера на телевизор.

## Установка

Выполните на компьютере, с которого видео будет идти на телевизор:

```sh
curl -fsSL https://rutorrcast.anysda.space | sh
```

Установщик скачает последний выпуск, проверит контрольную сумму SHA-256, поставит зависимости и настроит фоновые службы. При необходимости запросит права администратора. Если найдётся ровно один приёмник, выберет его автоматически. Программа будет на русском; `cast --en` переключает сохранённый язык, включая сообщения в терминале, ответы бота и предпочтения при выборе озвучки, а `cast --ru` возвращает обратно.

Теперь включите фильм:

```sh
cast матрица
```

Если приёмников несколько, выберите нужный через `cast --tv`, затем повторите команду запуска фильма. Адрес можно задать и напрямую: `cast --tv <ip>`.

<details>
<summary>Установка на macOS</summary>

Тот же однострочник работает на macOS нативно. Запускайте его из своей обычной учётной записи с правами администратора. Установщик сам поставит Homebrew, если его ещё нет, и настроит фоновые службы через launchd.

Чтобы фоновая служба могла обращаться к локальной сети, показ работает от root. Установщик добавляет для вашего пользователя правило sudo без пароля, только для команды `cast`. Фильмы по-прежнему запускаются обычной командой `cast матрица`.

Загрузчик требует `sha256sum` ещё до установки Homebrew. Если он остановился на сообщении `нужен sha256sum, его нет в PATH`, воспользуйтесь установкой из репозитория ниже: она запускает `install.sh` напрямую. Если macOS спросит, разрешить ли входящие подключения, разрешите их, чтобы приёмник мог получить видеопоток.

</details>

<details>
<summary>Установка из репозитория</summary>

```sh
git clone https://github.com/anysda/torrcast
cd torrcast
./install.sh -ru
```

Здесь установщик тоже сам займётся зависимостями и запросит нужные права. На ARM Linux понадобится рабочий ffmpeg 6.1+, если его нет в пакетах дистрибутива: запасная сборка установщика для Linux рассчитана на x86_64.

</details>

## Просмотр

Обычно достаточно названия. Добавьте `--menu`, если хотите выбрать фильм сами, например когда нашлось несколько частей:

```console
$ cast матрица --menu
  1. Матрица (1999) · IMDb 8.7 · 2 ч 16 мин
     Научно-фантастический боевик, снятый Вачовски по собственному сценарию.
  2. Матрица: Перезагрузка (2003) · IMDb 7.2 · 2 ч 18 мин
     Научно-фантастический боевик, второй фильм серии «Матрица».
  3. Матрица: Революция (2003) · IMDb 6.7 · 2 ч 9 мин
     Научно-фантастический боевик, третий фильм серии «Матрица».
Enter - «Матрица (1999)», пункт 1 из 3
Что смотрим? [1]:
```

Нажмите Enter, чтобы включить предложенный фильм, или введите номер. Выдача, рейтинги и доступные версии могут меняться. torrcast собирает версии одного фильма в один пункт: вы выбираете сам фильм, а подходящую версию программа подберёт.

Для сериала можно указать сезон и серию:

```sh
cast ким пять с плюсом s1e1
```

Следующая серия начнётся автоматически. `cast stop` сохранит место, а **`cast` без аргументов продолжит последний сериал**. Чтобы продолжить фильм, снова укажите его название.

Ставить на паузу и перематывать можно телевизионным пультом. После начала показа терминал можно закрыть, а SSH отключить. torrcast сам управляет кэшем; собирать и упорядочивать медиатеку не нужно.

## Home Assistant

Добавьте torrcast на дашборд: с карточки можно включить фильм, поставить на паузу, перемотать, изменить громкость или перейти к следующей серии. Интеграция подключается к torrcast по локальной сети.

[![Добавить torrcast в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=anysda&repository=torrcast&category=integration)

1. Установите torrcast командой выше. Затем кнопкой добавьте его [пользовательский репозиторий в HACS](https://www.hacs.xyz/docs/faq/custom_repositories/) и скачайте интеграцию.
2. Перезапустите Home Assistant. В разделе **Настройки > Устройства и службы** подтвердите найденное устройство torrcast. Если оно не появилось, добавьте интеграцию torrcast вручную, указав IP компьютера и порт `8479`.
3. Добавьте медиаплеер на дашборд. В его браузере медиа откройте **instant**, чтобы ввести название и сразу запустить показ, или **menu**, чтобы найти фильм и выбрать его из списка.

Управлять показом можно и через Assist. Запуск фильма по названию зависит от языка ассистента: в проверенной конфигурации встроенный Assist понимает такой запрос на английском, но не на русском. Вводить русские названия в браузере медиа можно независимо от этого ограничения голосового управления.

## Telegram

Отправьте `cast матрица`, устроившись на диване, и управляйте показом кнопками в чате. Бот сообщает, как идёт запуск, а затем показывает пульт: пауза, стоп, громкость и перемотка на 30 секунд. Он подхватит и показ, запущенный из терминала или Home Assistant.

Настройте бота на компьютере с torrcast:

```sh
cast -tg
```

Создайте бота через [BotFather](https://core.telegram.org/bots/features#botfather), откройте с ним чат и нажмите **Запустить**. В меню настройки введите токен бота и ID своего чата, затем выберите **Проверить и сохранить**. Вы получите пробное сообщение, а служба бота включится и будет запускаться после перезагрузки. Бот принимает команды только из указанного чата.

<details>
<summary>Где взять ID чата</summary>

Пока служба бота ещё не включена, отправьте новому боту сообщение. Откройте в браузере `https://api.telegram.org/bot<TOKEN>/getUpdates`, заменив `<TOKEN>` токеном из BotFather. В [ответе](https://core.telegram.org/bots/api#getupdates) найдите число в `result[].message.chat.id` и скопируйте его в поле **ID чата** в меню настройки.

</details>

Пишите обычными сообщениями:

```text
cast матрица
cast ким пять с плюсом s1e1
cast
cast stop
```

Телефон передаёт команды через Telegram, а видео идёт между компьютером и телевизором.

## Команды

| Команда | Действие |
| --- | --- |
| `cast <название>` | Найти фильм или сериал и включить. |
| `cast <название> s1e1` | Включить конкретную серию: сезон и номер. |
| `cast` | Продолжить последний сериал. |
| `cast stop` | Остановить показ и сохранить место. |
| `cast status` | Что играет, на каком месте и сколько загружено вперёд. |
| `cast <название> --menu` | Показать найденные картины и спросить, а не включать сразу. |
| `cast <название> --pick N` | Картина N из меню, без вопроса. |
| `cast <название> --new` | Та же раздача, файл и дорожка с начала. |
| `cast <название> --voice` | Выбрать озвучку из меню. `--voice N` или `--voice СТУДИЯ` выбирает и запоминает. |
| `cast voices <название>` | Показать доступные дорожки до запуска. |
| `cast releases <название>` | Показать релизы по картинам. `--release N` с тем же запросом включает нужный. |
| `cast <название> --dry` | Пройти весь подбор, не включая показ. |
| `cast --tv` | Найти приёмники в сети и выбрать из списка. `cast --tv <ip>` задаёт адрес напрямую. |
| `cast -tg` | Меню настройки Telegram-бота. |
| `cast --ru` / `cast --en` | Переключить язык и запомнить выбор. |
| `cast doctor` | Проверить службы, сеть и приёмник. |
| `cast log --since 2d` | Диагностический след. `--since` принимает `2d`, `12h`, `30m` или дату `ГГГГ-ММ-ДД`. |
| `cast --upgrade` | Обновить до последнего выпуска. |
| `cast --version` | Показать версию. |
| `cast -h` | Все команды и параметры. |

## Обновления и помощь

```sh
cast --upgrade
```

Обновление сохраняет настройки и выбранный приёмник. Пока что-то играет, оно откажется запускаться.

Если фильм не запускается, выполните `cast doctor`: он проверит службы, сеть и приёмник. `cast log --since 2h` покажет недавние события просмотра, а `cast -h` перечислит команды и параметры.

Об ошибке можно [сообщить в issue](https://github.com/anysda/torrcast/issues). Укажите команду, которую запускали, ОС и модель приёмника, приложите относящийся к проблеме вывод диагностики.
