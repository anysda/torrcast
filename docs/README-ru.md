# torrcast

**Назвал фильм - и он уже играет на телевизоре.**

Одна команда в терминале находит фильм, сериал или аниме по названию и выводит его на
телевизор. Без облака в пути данных, без медиатеки и очередей закачек, без ручного
перебора раздач и звуковых дорожек. Поток идёт напрямую: из роя на ваш сервер, оттуда на
телевизор. Третьих сторон между вами и картинкой нет.

## Как это выглядит

```console
$ cast матрица --menu
поиск «матрица»... 2.4 с
  1. Матрица (1999) · IMDb 8.7 · 2 ч 16 мин
     «Матрица» - научно-фантастический боевик 1999 года, снятый по собственному
     сценарию Вачовски.
  2. Матрица: Перезагрузка (2003) · IMDb 7.2 · 2 ч 18 мин
     ...
  3. Матрица: Революция (2003) · IMDb 6.7 · 2 ч 9 мин
     ...
Enter - «Матрица (1999)», пункт 1 из 3
Что смотрим? [1]:
ищу русскую озвучку: релиз 1 из 47 - дорожки... 2.3 с
упаковка... 3.1 с
жду телевизор... 1.2 с
играю «Матрица» (1999) · 1080p · rus · Дубляж - на ТВ   (старт 9 с)
```

без `--menu` вопроса не будет вовсе, torrcast возьмёт самую
живую картину и назовёт её вслух одной строкой. `старт 9 с` - это время до первого живого
кадра на экране, а не до момента, когда приёмник отрапортовал о готовности. Дальше пульт
снова главный: пауза и перемотка работают как с любым другим источником. Прогон сокращён,
потому что номера релизов, сиды и тайминги меняются вместе с ответами индексеров и роя.

## Почему это удобно

- **Одна команда.** Спросил - и оно играет. Ни выбора релиза, ни очереди загрузок, ни
  хозяйства звуковых дорожек. Часто вообще без единого вопроса.
- **Сериалы идут сами.** Следующая серия стартует без вопроса и без переподключения к
  телевизору. Кончился сезон - torrcast сам ищет следующий и продолжает с первой серии.
  Кончился сериал - скажет об этом честно.
- **Озвучка выбирается сама.** По языку продукта: русская установка ставит русские
  дорожки первыми, английская - английские. `cast <запрос> --voice СТУДИЯ` запоминает
  любимую озвучку этой картины навсегда.
- **Интернет может пропасть, кино нет.** Пока вы смотрите, фильм фоном прогревается на
  диск целиком. После прогрева досматриваете без сети вообще, вместе с перемоткой.
- **Ничего лишнего на диске.** Кэш живёт ровно столько, сколько длится просмотр. Нет
  медиатеки, нет «надо бы почистить».
- **Плавность важнее цифр.** Релиз тяжеловат для приёмника - тяжёлые куски
  перекодируются на лету. Качество жертвуется в последнюю очередь и ровно настолько,
  насколько нужно, чтобы не было буферизации.
- **Говорит по-русски и по-английски.** `cast --ru` и `cast --en` переключают весь
  продукт: надписи, сообщения, ответы бота и ту озвучку, которую он ищет.
- **Telegram-бот.** `cast -tg`, и телевизором можно управлять из чата. Настройка
  сажает бота на службу, поэтому чат отвечает и после перезагрузки.
- **Честно.** Ни одной молчаливой подмены. У каждого автоматического решения своя
  понятная строка:

```text
релиз 1 на деле 574p - беру 2 (настоящий 1080p)
внимание: ~36 Мбит/с - тяжёлые куски перекодирую на ходу
видео hevc - перекодирую на ходу целиком
```

## Чем torrcast не является

- **Не торрент-качалка.** На диске только то, что играет, и только пока играет.
- **Не медиасервер.** Нет библиотеки, нет веб-морды, нет учёток. Есть команда.
- **Не облачный сервис.** Никакого стороннего сервера в пути потока: адрес для
  телевизора вычисляется по маршруту до него, и DNS в пути воспроизведения не участвует.

## Установка

```sh
curl -fsSL https://rutorrcast.anysda.space | sh
```

Это русская версия продукта, английскую ставит `https://torrcast.anysda.space`. Выбор не
окончательный: `cast --ru` и `cast --en` переключают уже поставленную копию в любой
момент. Однострок спрашивает у GitHub последнюю версию, тащит тарбол ровно этой версии,
сверяет его контрольную сумму SHA-256 и идемпотентен: повторный запуск обновляет только
изменившееся. Ни регистрации, ни внешних ключей API не нужно.

Требования: Linux с systemd (Debian 12 и новее либо Ubuntu, установка ходит в `apt`),
Python 3.11 и новее, права root на установку, около 33 ГБ свободного диска под прогрев и
телевизор или приставка со встроенным приёмником Chromecast в той же сети. Замеры сняты
на машине с 8 ГиБ памяти; на меньшей просто меньше кэш.

Из исходников:

```sh
git clone https://github.com/anysda/torrcast && cd torrcast
./install.sh -ru
```

Ключ называет язык руками: `-ru` ставит русскую копию, `-en` английскую. Права root
установщик спрашивает сам: запущенный обычным пользователем, он перезапускается через
`sudo`, а на машине, где ты уже root, `sudo` не нужен вовсе.

Приёмник установка находит сама - по mDNS и обходом локальных подсетей. Их несколько -
`cast --tv` покажет список, `cast --tv <ip>` запишет адрес напрямую.

Поставленная копия обновляет себя сама: `cast --upgrade` спрашивает у GitHub
последнюю версию и, если она не совпала с установленной, тащит её и зовёт ту же
установку. Совпала - говорит об этом и не трогает ни единого файла. Идущий показ он не
обрывает, а приёмник и настройки оставляет как есть.

## Команды

```text
cast <запрос> [sNeM]    # найти и включить; sNeM - сезон и серия: cast "доктор кто" s2e5
cast                    # что играет сейчас (то же, что cast status)
cast stop               # снять каст и сохранить позицию
cast status             # позиция, файл, дорожка, раздача, доля прогретого
cast doctor             # проверка терминала, ffmpeg, служб, приёмника и раздачи
cast log [--since 2d]   # журнал сеансов: каждый ребуфер и обрыв
cast voices <запрос>    # звуковые дорожки релиза, который поедет на телевизор
cast releases <запрос>  # таблица релизов по картинам
cast -tg                # настройка Telegram-бота
cast --tv               # найти приёмники в сети
cast --upgrade          # обновить до последнего релиза или сказать, что он уже стоит
cast -h                 # справка по всем ключам
```

Полезные ключи: `--menu` (спросить, какую картину), `--pick N`, `--release N`,
`--voice [N|СТУДИЯ]`, `--new` (тот же релиз с начала), `--dry` (весь разбор без каста).
Недосмотренное продолжается молча: та же раздача, тот же файл, та же дорожка, сохранённая
позиция. Строка показа скажет об этом и назовёт выход из неё.

## Под капотом

```text
запрос -> поиск (Prowlarr) -> разбор (имена релизов, франшизы, sNeM)
      -> поток (TorrServer) -> ffmpeg -> HLS -> каст (Chromecast)
                            \-> прогрев (фильм целиком на диск, фоном)
```

Постоянного демона воспроизведения нет: на каждый показ `cast` поднимает временный юнит
systemd с ffmpeg, HLS-сервером и наблюдателем позиции. Команда может завершиться, показ
продолжится. Прогрев читает вперёд вчетверо быстрее реального времени под `nice` и
замирает совсем, когда процессор нужен живому показу: место, которое смотрят прямо
сейчас, всегда в приоритете.

Приёмники замерены и описаны профилями (Samsung Q70D, приставка Android TV на Xiaomi TV
Stick); незнакомый приёмник получает осторожный профиль. HEVC на приёмнике без его
декодера перекодируется целиком, 2160p играется даунскейлом в 1080p, и об этом всегда
говорится вслух.

Код держится на жёстких рамках: слоистая архитектура (domain / ports / usecases /
adapters / cli / runtime), тестов больше, чем кода, линтер, строгий mypy и структурные
гейты обязаны проходить до любого релиза.
