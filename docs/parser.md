# Парсер имён раздач — решения и доказательства (этап 1)

Модуль `torrcast/parse.py`. Всё, что torrcast знает о картине, добыто из имени
раздачи: внешних API нет по §1 и §3 ТЗ.

## Решение по guessit (§6): не берём

**Одной строкой:** guessit на русских трекерах отдаёт русское название лишь в
**23,3 %** случаев (а нам нужно именно оно — ключи состояния §4 русские), на
kinozal-формате `Рус / Original / год / озвучки / источник` в **12,7 %** выдаёт
мусор вместо названия (`'EUR'`, `'AVO'`, `'1988'`), то есть свой сплиттер названий
писать всё равно пришлось бы — а качество/кодек, ради которых её и берут, это
десяток регэкспов.

Замер: 1500 случайных уникальных имён из rutor / kinozal / RuTracker / megapeer,
guessit 4.4.0.

| метрика | guessit |
|---|---|
| `title` содержит кириллицу (нужное нам русское название) | 23,3 % |
| `title` — явный мусор (год, тег озвучки, код профиля) | 12,7 % |
| год не извлечён | 4,1 % |

Характерные провалы:

```
Крепкий орешек (Квадрология) / Die Hard: Quadrology / 1988-2007 / ДБ, ПМ, СТ / …   → title='1988'
Интерстеллар / Interstellar (IMAX Edition) / 2014 / ДБ, СТ / 4K, HEVC / Blu-Ray EUR → title='EUR'
Во все тяжкие / Breaking Bad / S1E1-62 of 62 (Винс Гиллиган) [2008-2013, …]         → title='AVO'
Супергёрл / Supergirl / 2026 / ДБ, СТ / 4K, HEVC, HDR, Dolby Vision P8 / Hybrid     → title='P8'
```

Плюс это +4 транзитивные зависимости (`rebulk`, `python-dateutil`, `six`) в
проекте, у которого весь список — `requests` и `catt`.

Свой парсер — 511 строк `parse.py` (404 без пустых строк и комментариев) вместе
с кластеризацией франшиз и разбором эпизодов, которых в guessit нет вовсе.

⚠️ Бюджет §6 (≤ ~1200 строк на пакет) при этом выбран: пакет сейчас 1455 строк
физических / 1175 без пустых. Решение — за оркестратором: либо счёт вести по
строкам кода, либо ужимать `stream.py`/`cli.py` на следующих этапах.

## Что парсер понимает

| формат | пример |
|---|---|
| rutor / megapeer | `Рус / Original (2024) BDRip 1080p от Кто-то \| D, P, A` |
| kinozal | `Рус / Original / 2009 / ДБ, СТ / 4K, HEVC / Blu-Ray Remux (2160p)` |
| rutracker | `Рус / Original (Режиссёр) [2009, США, боевик, BDRip] Dub + AVO + Sub` |
| scene | `The.Martian.2015.1080p.BluRay.REMUX.AVC-FGT` |
| аниме | `[Group] Title (2025) (WEB-DL 2160p DV HEVC) [A1D6970F] \| alt` |

Извлекается: русское название, оригинал, год, качество, кодек (+флаг HEVC),
источник (BDRip/WEB-DL/Remux/…), HDR, озвучки, сезон и серия, признак «не видео»
(музыка / книги / игры отсеиваются, чтобы не попадать в меню фильмов).

### Что за хвост — честно

Низкие проценты у TPB/apibay/nyaa — это **не провал разбора, а отсутствие года в
самом имени**. Колонка «назв+год там, где год в строке есть» = 96,5 % даже по
хвосту. Топ шаблонов «непарсящихся»:

| шт. | источник | что не так | пример |
|---|---|---|---|
| 1091 | nyaa | года нет в имени | `(H.A.L)[Zettai] Cowboy Bebop (BD 1080p x264 FLAC 5.1) (pt br)` |
| 765 | apibay | года нет в имени | `109 East Palace: Oppenheimer and the Secret City of Los Alamos` |
| 564 | TPB | scene-сериал без года | `A Knight of the Seven Kingdoms S01E01 … 1080p AMZN WEB-DL H 264-FLUX` |
| 270 | Nyaa.si | пак из десяти фильмов одной строкой | `80s ANIME Movies Pack 1: Toward the Terra,Nausicaa…` |
| 182 | anidub | не кино (OST, сборники) | `Japano-музыка [HIGH and MIGHTY COLOR]` |
| 122 | anilibria | аниме-равки без года | `Blade and Soul - AniLiberty.TOP [HDTVRip 720p][AVC][1-13]` |
| 103 | RuTracker | музыка, отсеяна как не-видео | `(Chill Out) VA - Dune 1-3 - 2018-2021, AAC (tracks)` |

Для сериала отсутствие года не мешает: название извлекается, кластеризация и
`sNNeNN` работают, а год в ключе состояния становится `0`.

Отдельно отсеяно как не-видео (музыка / книги / игры): **1429** имён из 21 540.

## Известные ограничения (не чиним в MVP)

* Форма `Latin (год) | Русское [ТВ-1] [год]` (animelayer, часть anilibria): берётся
  латинское название, русское теряется — год стоит между ними. Кластеризация от
  этого не страдает, форма редкая (< 300 имён на корпус).
* Названия со словом-стоппером внутри (`The Mortuary Collection`,
  `Shingeki no Kyojin: The Final Season`) обрезаются по этому слову.
* Сборники сезонов `[S01-06]` дают `season=1`: это пак, а не первый сезон.
* CJK-имена без латиницы/кириллицы дают `title='?'`.

## Кластеризация франшиз (§2.2)

1. Релизы группируются по `(тип, slug названия, год)`; варианты перевода с общим
   **оригиналом и годом** сливаются («Матрица 2: Перезагрузка» + «Матрица:
   Перезагрузка» → одна картина, каноничным становится частотный вариант).
2. Кросс-язычность: карта `slug(оригинала) → slug(русского)` строится по тем
   раздачам, где в имени есть оба варианта. Поэтому чисто латинская раздача
   `Cars 3` попадает в кластер «Тачки 3», а запрос `cast cars 2` находит «Тачки 2».
3. Франшиза = картины с общим `franchise_key` (название без подзаголовка после
   двоеточия и без хвостового номера), отсортированные по году.
4. Номер в запросе — индекс в этой хронологии. Если у картины есть **явный номер
   части** (подсмотренный в любом варианте перевода названия), он сильнее позиции:
   так `cast матрица 2` даёт «Перезагрузку», а не «Революцию», хотя обе 2003 года,
   и `cast тачки 2` даёт «Тачки 2», а не спин-офф «Мультачки» 2008 года.
